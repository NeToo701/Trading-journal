# Тембр — музичний плеєр (Google Диск + Firebase)

Статичний веб-застосунок без власного сервера. Працює на GitHub Pages, у браузері на Windows і на смартфоні.

- **Файли музики** зберігаються на вашому Google Диску, у папці «Тембр».
- **Метадані** (назва, виконавець, альбом, обкладинка, тривалість) зберігаються у Firebase Firestore.
- **Вхід** через акаунт Google. Кожен користувач бачить лише свою бібліотеку.
- **Плеєр** розгортається на велике вікно і згортається до компактної панелі знизу (кнопкою або свайпом вниз).
- **Плейлисти** (є готовий «Улюблені»), **текст пісень** із підсвічуванням, **статистика** прослуховувань.

## Налаштування (~15 хвилин)

Назви пунктів у консолях Google іноді змінюються, шукайте за змістом.

### 1. Firebase

1. <https://console.firebase.google.com> → **Add project** (Google Analytics можна не вмикати).
2. **Build → Authentication → Get started → Sign-in method → Google → Enable → Save**.
3. **Build → Firestore Database → Create database** (production mode, регіон найближчий до вас).
4. **Firestore → Rules** → вставте правила й натисніть **Publish**:

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

   > Якщо ви вже налаштовували проєкт раніше, **замініть** старі правила на ці й натисніть **Publish**. Без цього не
   > працюватимуть плейлисти, статистика й порядок списку (у застосунку з'явиться повідомлення про права доступу).
5. **Project settings (⚙) → General → Your apps → Web (</>)** → зареєструйте застосунок →
   скопіюйте `apiKey`, `authDomain`, `projectId`, `appId` у `config.js`.
6. **Authentication → Settings → Authorized domains → Add domain**: `ВАШ-ЛОГІН.github.io`
   (для локальної перевірки `localhost` там уже є).

### 2. Google Cloud (той самий проєкт)

1. <https://console.cloud.google.com>, оберіть проєкт Firebase.
2. **APIs & Services → Library → Google Drive API → Enable**.
3. **OAuth consent screen** (або «Google Auth platform»): тип **External**, назва «Тембр», ваш email.
   - **Scopes**: додайте `.../auth/drive.file`. Це доступ лише до файлів, створених цим застосунком,
     а не до всього вашого Диска.
   - **Test users**: додайте свою пошту (поки застосунок у режимі Testing). Щоб користуватися
     з інших акаунтів, натисніть **Publish app**: перевірка Google для `drive.file` не потрібна.
4. **Credentials → OAuth 2.0 Client IDs → «Web client (auto created by Google Service)»** → відкрийте →
   **Authorized JavaScript origins** → додайте:
   - `https://ВАШ-ЛОГІН.github.io` (без `/назва-репозиторію` і без слеша в кінці)
   - `http://localhost:8080` (для перевірки на своєму комп'ютері)

   Збережіть. Скопіюйте **Client ID** у `googleClientId` у `config.js`.

### 3. GitHub Pages

1. Створіть репозиторій на GitHub і завантажте в нього **весь вміст папки проєкту** (з папками `css` і `js`).
2. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
3. Через хвилину сайт відкриється за адресою `https://ВАШ-ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/`.

### Перевірка на своєму комп'ютері

У папці проєкту: `python -m http.server 8080`, потім <http://localhost:8080>.
Вхід через Google працює лише з адрес, доданих в Authorized JavaScript origins (не з `file://`).
Якщо `config.js` не заповнено, на екрані входу з'явиться підказка.

## Як це працює всередині

- Вхід: Google Identity Services видає токен із правом `drive.file`; цим токеном виконується вхід у Firebase Auth.
  Токен дійсний близько години. Після оновлення сторінки його треба відновити: застосунок зробить це на
  першому натисканні ▶ або «Завантажити» (може на мить з'явитися вікно Google).
- Завантаження: файл вантажиться на Диск (resumable upload з індикатором прогресу), теги й обкладинка читаються
  з файлу (ID3), метадані пишуться у `users/{uid}/tracks`.
- Відтворення: `sw.js` (service worker) стрімить файл із Диска частинами (HTTP Range), тому трек грає майже одразу,
  а перемотка працює без повного завантаження. Наступний трек підвантажується у другий `<audio>`, і перемикання
  відбувається миттєво. Якщо стрімінг із якоїсь причини не спрацював (service worker не активний, помилка Диска),
  застосунок сам завантажує файл цілком і грає з того ж місця.
- Імпорт: усе, що додається (файли, папка, перетягування, «Поділитися»), спершу потрапляє у список у діалозі
  «Додати музику». Там можна позначити все або частину, відфільтрувати, додати ще файли з інших папок. Не-музичні файли
  пропускаються, файли, що вже є в бібліотеці (ім'я + розмір), не позначаються. Завантаження починається після «Додати».
- Черга: це список треків, який зараз грає, і позиція в ньому. Вона зберігається у браузері (окремо для кожного пристрою
  й акаунта), у тому числі в режимі випадкового порядку: після перезавантаження сторінки черга та сама. Кнопка скидання
  черги біля пошуку очищає її. У випадковому режимі повернення назад іде тим самим шляхом, яким ви слухали.
- Текст пісні: вставляється вручну або шукається в Інтернеті в базі LRCLIB (<https://lrclib.net>). Якщо знайдено текст
  із часовими мітками (LRC), поточний рядок підсвічується й прокручується, а слова в ньому зафарбовуються
  по ходу рядка, як у Spotify. У LRC є час лише для рядків, тому підсвічування окремих слів **наближене**: воно
  розподіляється за довжиною слів. Текст без міток просто показується, його можна прокручувати. Для самостійно
  вставленого тексту можна вставити й LRC із мітками `[01:23.45]`.
- Статистика (бокова панель → «Статистика»): прослуховування рахуються за календарними періодами, а не за «останні N днів».
  Жовтень — це весь жовтень, навіть якщо ви почали слухати в середині місяця. Вкладки: **Тиждень** (ISO-тижні пн–нд,
  показуються останні 5), **Місяць** (останні 12), **Рік** (останні 5). Трек зараховується, коли відіграно 30 секунд або
  половину тривалості (що менше). Дані лежать у `users/{uid}/stats` у Firestore.
- Файли в папці «Тембр» не перейменовуйте й не видаляйте вручну: список треків живе у Firebase і посилається на них.

## Керування

- Клавіші: **Пробіл** — пауза/відтворення, **Shift + →/←** — наступний/попередній трек, **Esc** — згорнути плеєр на телефоні.
- Файли й цілі папки можна перетягнути у вікно браузера (комп'ютер).
- Кнопка зі стрілкою (або свайп вниз по великому плеєру на телефоні) згортає великий плеєр до панелі знизу, натискання
  на панель розгортає його назад. Вибір запам'ятовується окремо для комп'ютера й телефона.
- **Меню ⋮** біля кожної пісні: змінити назву, змінити виконавця (можна додати кількох), додати до плейлиста, змінити
  обкладинку, текст пісні, видалити. На телефоні меню відкривається знизу.
- **Серце** у великому плеєрі додає пісню до «Улюблені».
- **Плейлисти**: вкладка «Плейлисти» нагорі. Створення, перейменування, видалення, відтворення плейлиста.
- **Сортування списку**: нові спочатку, старі спочатку, за назвою А→Я та Я→А, **довільний**. У довільному порядку
  пісні перетягуються за значок ⋮⋮ ліворуч, порядок зберігається в акаунті. Під час пошуку перетягування вимкнене.
- **Кабінет**: кругла кнопка з літерою справа вгорі відкриває бокову панель: «Статистика» і «Вийти».

## Імпорт музики з телефона

Файловий менеджер на деяких телефонах (наприклад, Xiaomi) не дає вибрати багато файлів, а музика лежить по різних папках.
Є три способи, їх можна комбінувати: все потрапляє в один список перед завантаженням.

1. **«Папка»**: оберіть папку, і Тембр сам знайде в ній (разом із вкладеними) усю музику, а решту файлів пропустить.
   Повторіть для інших папок. Працює не в усіх мобільних браузерах: якщо відкрився звичайний вибір файлів, скористайтеся п. 2 або 3.
2. **«Поділитися»** (потрібен встановлений застосунок, див. нижче): у файловому менеджері відкрийте розділ «Аудіо»
   (він показує всю музику телефона), виділіть усе довгим натисканням → **Поділитися → Тембр**. Файли з'являться у списку імпорту.
3. **«Файли»** / **«Будь-які файли»**: звичайний вибір кількох файлів; другий варіант без фільтра типу, якщо провідник
   не показує музику.

## Встановлення на телефон (Chrome)

1. Відкрийте сайт у Chrome, увійдіть, зачекайте кілька секунд (service worker має встановитися).
2. Меню ⋮ → **Установити застосунок** (або «Додати на головний екран»). Іконка «Тембр» з'явиться як у звичайного застосунку.
3. Після встановлення Тембр з'явиться в меню «Поділитися» для аудіофайлів.

Якщо пункту «Установити застосунок» немає: оновіть сторінку з очищенням кешу (у налаштуваннях сайту «Очистити дані») і
перевірте, що в репозиторії є `sw.js` (у корені) та папка `icons`.

## Структура

```
index.html          сторінка
config.js           ваші ключі (Firebase, Google Client ID)
css/style.css       стилі (ПК і смартфон)
js/app.js           інтерфейс і програвач
js/importer.js      діалог імпорту (файли, папки, «Поділитися»)
js/queue.js         черга відтворення (випадковий порядок, повернення назад, збереження)
js/ui.js            вікна, меню ⋮, підтвердження
js/lyrics.js        текст пісень: розбір LRC, пошук у LRCLIB, підсвічування
js/stats.js         сторінка статистики
js/store-cloud.js   Google Диск + Firebase
js/stream.js        зв'язок зі service worker
js/meta.js          читання тегів і обкладинки
js/utils.js         дрібні функції
sw.js               service worker: стрімінг із Диска, прийом файлів із «Поділитися»
manifest.webmanifest, icon.svg, icons/   встановлення на телефон
```

## Обмеження

- Стрімінг працює через service worker: потрібен HTTPS (GitHub Pages підходить) і сторінка, що завантажилась уже після
  встановлення воркера. Після жорсткого оновлення (Ctrl+F5) воркер на мить не керує сторінкою, тоді працює запасний режим.
- Токен Google живе близько години. Після цього при наступній дії (▶, «Додати») може коротко з'явитися вікно Google.
  Вікно Google можна відкрити лише після дотику до екрана, тому при вимкненому екрані оновити токен неможливо.
  Щоб музика не зупинялася, Тембр завантажує в пам'ять 3 наступні треки черги цілком (1 трек, якщо ввімкнено
  «Заощадження трафіку»). Вони грають без мережі й без токена. Якщо музика грає, а токен скоро закінчиться,
  він оновлюється при найближчому дотику. Якщо екран вимкнено понад годину й закінчилися завантажені наперед треки,
  черга зупиниться на наступному треку; після розблокування натисніть ▶.
- Під час імпорту тримайте вкладку відкритою (на телефоні екран не гаситься сам, якщо браузер це дозволяє).
- Пошук тексту залежить від бази LRCLIB: далеко не всі пісні там є (особливо рідкісні й нові), тоді текст можна вставити
  вручну.
- Черга зберігається лише в тому браузері, де ви слухали; між телефоном і комп'ютером вона не синхронізується.
- Немає роботи офлайн.
